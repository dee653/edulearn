# EduLearn Academy - Job-Ready Tech Education Platform

A modern, multi-page web platform for **EduLearn Academy of Technology**, designed and developed using semantic HTML5, modern CSS3 (Custom Properties & Flexbox/Grid), and vanilla JavaScript (ES6+).

---

## 🌟 Key Features

- **Indian Rupee (₹) Pricing & Cohort Management**: Fully localized course pricing in ₹ with EMI calculators, real batch start dates, and syllabus specifications.
- **Natural Emerald & Amber Palette**: Handcrafted, human-designed aesthetic using British Racing/Deep Forest Green (`#0c5e3f`) and Warm Terracotta (`#c2410c`), eliminating generic AI template blues/purples.
- **Institutional Credibility**: Real-world faculty profiles, Bengaluru campus office details, hiring partner networks, and alumni placement testimonials.
- **Dynamic Course Filtering & Search**: Instant client-side course filtering by category (Web Engineering, Data Science & AI, UI/UX, Growth Marketing) and live keyword search.
- **Interactive Multi-Page Architecture**:
  - `index.html` - Homepage with Hero section, hiring partners ticker, flagship cohorts, verified alumni outcomes, and CTA.
  - `courses.html` - Complete course catalog with filter buttons, live search, and detailed syllabus badges.
  - `about.html` - Mission, engineering philosophy, faculty profiles, and institutional pedigree.
  - `blog.html` - In-depth engineering articles, interview guides, and roadmap breakdowns.
  - `contact.html` - Admissions contact form with live validation and Bengaluru campus Google Map.
  - `login.html` - Student LMS Portal with tabbed Login and Registration forms.
- **Responsive & Accessible**: Seamlessly adapts from desktop to tablets and mobile devices with fluid typography and a clean hamburger navigation menu.

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Chrome, Edge, Firefox, Safari)
- Optional: A local HTTP server such as Apache (via XAMPP), PHP, or Python

### Running Locally

#### Option 1: PHP Built-in Server
```bash
php -S 127.0.0.1:8000
```
Then navigate to: [http://127.0.0.1:8000](http://127.0.0.1:8000)

#### Option 2: XAMPP Apache
1. Place the folder inside your `htdocs` directory (e.g., `c:\xampp\htdocs\Edutech`).
2. Start Apache from the XAMPP Control Panel.
3. Open: [http://localhost/Edutech/](http://localhost/Edutech/)

#### Option 3: Direct File Opening
Double-click `index.html` to open directly in any browser.
